# Articulated spell parts, v3

Asset: `Skill/VFX/rig-parts-v3.png`, 1774×887 RGBA. Generated with built-in ImageGen, followed by a layout/material edit. Original alpha is preserved. The actual layout is not an even grid: measured complete component rectangles are stored in `js/11d-spell-imagery.js`.

The active renderer no longer loads the v2 full sword/dragon/phoenix paintings. Dragon head, torso scales, tail and claws are independent sprites. The body follows the head's earlier path through 28 joints; the head dives onto the damage point at the hit time. Phoenix wings use shoulder and elbow joints with shared feather overlap; body flight, wings, tail feathers and talismans have separate poses. Each sword/crescent follows its own trajectory. Fields summon separate weapons or talismans around the boundary. None of these actors uses the previous full-picture sway/deformation.
