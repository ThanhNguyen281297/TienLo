# Painted equipment icons

Six individual transparent PNGs, generated with built-in ImageGen for this game:
Taoist robe, jade pendant, jade ring, embroidered boots, ritual cauldron and
healing potion. Weapon icons continue to use each class's own weapon PNG.

Shared direction: premium hand painted xianxia game item, gold / jade / navy
materials, complete centered object, clear silhouette at inventory cell size,
transparent background, no frame or text. Every item is generated separately;
these are not cropped from a sprite sheet. Rarity remains communicated by cell
border and item details, while empty equipment slots use dimmed icons.
